print(docs @ query)    # [2 0 1]The reason is that doc4 = [5, 5, 5] is just doc1 = [1, 1, 1] scaled up.
 Both point in exactly the same direction, meaning the same topics in the same proportions. 
The dot product rewards a vector’s length as well as its direction, 
so a long document that repeats itself beats a short, equally relevant one.

Real systems fix this with cosine similarity, which divides the dot product by the lengths of both vectors.
 That cancels the size and leaves only the direction:

def cosine(a, b):
    return (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))

np.linalg.norm(a) is the vector’s length. Most embedding search in RAG uses this or an equivalent.
