A NEURAL NETWORK PROJECT TO SOLVE A SIMPLE PUZZLE .


puzzle :
the networks get 2 inputs 0 and 1 and should give output 1 if both numbers are different and 0 if both numbers are same.

we have 2 inputs 1 hidden layer with 2 neurons.

recap of how a neuron works :
IN SIMPLE : a neuron multiply its inputs by their weights and adds a bias to it . 
THEN passes the total to ana activation function and sends the output to the next layer .
in this project our hidden neuron use the activation function called 
REL(U): IT keeps positive values and turn negagive ones into zero.

the ouput neuron uses the activation function called;
sigmoid: which squashes its total between the number 0 and 1 .
